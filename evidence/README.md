# Evidence

- `offline/` — the graded run, produced by `scripts/run_offline_evidence.ps1` with the internet off.
- `rehearsal/` — an online rehearsal on the same local model (labelled; not the graded run).
- `screenshots/` — Obsidian and terminal screenshots.
- `logs/` — every search/ask/chat record as JSON lines, plus ingest logs.

Nothing here is edited by hand except the Assessment sections of the cards.
