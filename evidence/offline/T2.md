## Gemma's answer (verbatim)

> The model stopped working when the digits were moved over by a few pixels because it learned which coordinates in a $28 \times 28$ box tend to be lit, given MNIST's centering, rather than learning what a specific digit looks like [S5]. This resulted in blurry fixed stencils when drawing each column of the weight matrix as a $28 \times 28$ image [S5].
